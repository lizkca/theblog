# 把每天发生的东西，提炼成一个点；你不是天生状态就好的。（2026年8月15日） 

- 1.第一步，看看山顶上有谁。放下教科书。你的第一任务，是找到这个专业“山顶”上都站着谁。去搜，粉末冶金的鼻祖，拿XX大奖的大牛，大师，大佬，大咖，大V，高手。。。。找到他们写的书，演讲视频访谈录，以及他们推荐的书单，学习策略，职业规划。从这些资源中获得的学习成果，比你抱着一本大学教科书啃，来得更直接，更有价值。
- 2.第二步，看看谁摔下来了。每个领域，都有一批，曾经登顶，又摔得粉身碎骨的“烈士”。一个摔下来的巨头，相当于用毕生心血，替你趟了遍雷区。这些纪录片，访谈，案例分析，价值千金。
- 3.先把结论砸在前面，微信公众号只适合大博主做自己的私域，小博主不可能通过公众号成长起来。这句话可能会劝退很多还在死磕公众号的新人，但这是我和身边一票做内容的朋友，踩了两年坑、熬了无数个写文改稿的深夜，换来的真心话。想搞懂“为什么你写的文章没人看”，先搞懂一个核心问题，用户到底是怎么看到公众号文章的？我把所有流量入口归为两类--生成式推荐和搜索式推荐，而这两条路，对零粉丝，低权重的小博主来说，全是死路。
- 4.用公众号的搜一搜，可以搜最热的文章。找到这些文章，看看别人是咋写的，有什么可以学吗？（公众号搜，有个排序，选择按最热排序。）
- 5.虽然你很感恩你周围的人。但是，当你拥有大量资源，你绝对不应该随便把资源给出去的。因为，那会破坏掉，弄混淆掉别人的努力。对别人，对你自己都没任何好处。
- 6.当你掌握资源了，要慢慢习惯抛弃弱者思维。与人发生矛盾时，即使你占理了，你也不一定非得争个输赢对错。要学会大度，大气一点。
- 7.把每天发生的东西，提炼一下，形成一个要点。然后，把这个要点，发展一下，再给到AI完善一下。那就有一篇文章了嘛。（不要忘了AI的巨大作用）
- 8.所以，那里需要头疼每天更新一篇文章呢。别忘了AI的巨大作用就是了。
- 9.人与人之间，其实也有三体关系的。例如，甲跟乙闹翻了，而恰巧甲跟丙也闹翻了，那么乙和丙的关系会咋样呢。乙和丙有点小的摩擦，但乙还是故作姿态，大方的和丙友好。
- 10.假如说你掌握了大量资源。那么，你可以这样想象一下。就是你在下棋那里，有了很高的积分（例如1800分），那又怎样呢。你变得不敢轻易下棋了。
- 11.我所有的书都是用一个“大钩子”来吸引读者。开篇先放一个钩子，再用“小钩子”来串联。为了增加读者黏合度和期待感，我会同时推进两个或三个故事线。这样，当一个“钩子”放下时，还有另一个“钩子”在吸引读者。
- 12.在接受封面新闻记者专访时，网文作家公子衍，透露了她在情节构思和故事进程安排上的技巧。她的网文作品《惊！天降老公竟是首富》改编的短剧《叮！我的首富老公已上线》上线后短短48小时内，充值流水突破1200万元。
- 13.她的小说，不靠复杂设定，而是靠钩子和多线叙事，来吸引读者。
- 14.有空，多看看书，分析分析别人的作品，尝试运用一下学到的东西，多实践一下，不好吗？
- 15.认真对待自己写的东西，不断修改完善自己写的东西。
- 16.还是要尽量不蛇王，保持这种有主心骨，敢，的状态。你一蛇王，就破坏这种状态了，变得不敢了，内心有亏欠，觉得自己不理直气壮了。
- 17.人生成功，靠的是，错位竞争，和降维打击。
- 18.2025年5月，《谷雨实验室》发布了一篇关于网文生存现状的调查，看完后，我最大的感受只有一句话，原来，写小说已经成为了真正意义上的高风险职业。
- 19.一位作者曾写给一本言情小说。小说里，女主只谈过一次恋爱，而男主有过几段感情经历。放在当年，这只是一个再普通不过的人物设定。可八年后，有人重新翻出这本小说。随后，一场针对作者本人的网络攻击开始了。有人公开了她的真实姓名，家庭住址，甚至精确到了门牌号。家人不断受到骚扰。

- 23.有问题，不见得就是坏事啊。如果你能为解决这个问题而做出一点点，哪怕只是一丁点的贡献，都非常非常好。
