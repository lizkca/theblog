# 两种积分牌；寻找力量来解决（2026年7月31日） 

- 1.反观那些写作高手，你会发现他们都有一套自己的阅读方法，能透过文字表面，读懂其中的写作技法，然后化为己用。
- 2.比如南派三叔读金庸时，并不仅沉溺于故事情节，他早就开始“琢磨多少字内这个人物说了几句话，这些话指向哪个情节点，为什么要这么写”。等把金庸的小说拆得只剩一个骨架时，他再把自己的故事情节往里边塞。
- 3.再比如王天挺读《被仰望与被遗忘》时，几乎把盖伊。特立斯的《纽约：被忽视之城》背了出来，对它的语感、组织材料的方式都了然如胸，最终才有了轰动一时的《北京零点后》。
- 4.写作可以通过有效阅读来提升吗？答案是肯定的。
- 5.很多职业作家在接受职业化的写作训练前，大多是靠自己的经验制作，但经过训练后，他们已经能得心应手地处理各种题材了。这期间他们经历了什么？
- 6.比如在美国哥伦比亚艺术学院，写作者们第一学年的任务，是在教授指导下，系统地读欧美和拉美的名著。然后临摹大师们各种类型的作品，直到高年级，才开始写自己的作品，逐渐形成一套自己的叙事方式和语言体系。
- 7.马尔克斯说过一句话，小说是用细节欺骗的艺术。你给读者足够的细节，他们就会相信。细节越具体，话说得越不动声色，读者就越容易上当。
- 8.写作是自我探索的好方法。
- 9.任何在你看来“做出来会很酷”的东西，无论听起来多么荒唐，都有很高的概率通向好的创业创意。因为你的潜意识知道，你的意识不知道的东西。
- 10.写作的底层逻辑，永远是把脑海零散思绪，精准梳理、落地成书面文字。高手和普通人的差距，只是熟练掌握了让文字贴合想法的表达技巧。
- 11.写不出来，大多不是文笔差，而是思维无法顺畅转化成语言；坚持动笔写作，恰好能反向打磨逻辑，倒逼思维变得条理清晰。
- 12.公众号、随笔文案、短视频脚本、职场汇报。。。写作早已褪去文学滤镜，从小众谋生技能，变成人人能用的实用工具。越早认清“写作由心，内容由我”，就越能抓住日常的变现和成长机遇。
- 13.有趣的是，你很久以前写的东西，感觉像是在你人生的不同时代，依然有生命力，并且能与陌生人互动。
- 14.放慢速度，让内心变得不急，才开始做事。
- 15.一直以来，你都是处于太多强迫了。找到你真实喜欢的，真实享受的东西，做好它。
- 16.搜一下B站，有没有AI写作方面的教程。
- 17.最大的感受是，写作真的要练就随时记录的能力。
- 18.脑海里只要浮现出一个值得观察的观点，就立刻写下来，别犹豫。一犹豫，灵感很可能瞬间跑掉，或者干脆没了记录的冲动。那这个想法就只能被搁置，没有机会被读者看见。
- 19.做自媒体，本质上就是输出自己观点的过程。如果我们什么都不说、不写，又怎么能让更多人看见呢？所以，只要是正向的观点，当它在你脑海里闪现的那一刻，就是提醒你，又有新的写作素材了，快记下来吧。
- 20.每一次记录，都是多一个人被看见的机会，也多一份成长和赚钱的可能。
- 21.昨天我发了6篇贴图，没写文章，整个人轻松不少。以前每次写完一篇长文，接下来好一阵都不想动笔。但贴图不一样，内容短，写起来快，我一口气能发三四条，也不会觉得太累。
- 22.因此，还是要找到适合自己的创作方式。喜欢写文章就写文章，喜欢发贴图就多发贴图。
- 23.顺着自己大脑和身体的节奏来，写作的状态自然就好很多。
- 24.这就好办了。在手机写作非常好用，要习惯在手机上写。随时随地都可以写东西，发表东西，这个非常重要。（今天，第一次用手机写了一篇公众号文章，并发表出去。）
- 25.之前总结的那个，学习技术框架。其实，也即是，要有一小部分东西，重复得足够多，变得足够熟练，已经内化成为你自己东西，然后，再添砖加瓦，增加新的东西。例如五笔，你要把你写的文章，用五笔反复打上多次，熟悉得很，就内化成你的东西，就形成框架了。
- 26.哈哈，又觉得有希望了。想想当你觉得完全没希望的时候（也就是今天上午而已），你真的认为很难，难到几乎没有任何希望了，你是咋想问题的。（都是白费力，肯定做不成的，。。。），而当你觉得有希望的时候，你又会咋想的，你会展开想象的翅膀，开始尽情的想象了，开始想入非非了。
- 27.有些东西，你写下来，和你只是想想，还真是大不一样。
- 28.这就是我今天想跟你说的最核心的一件事，一个我用99年的人生才彻底想明白的道理，人这一辈子最关键的选择不是你做什么，而是你用哪一张积分牌来衡量自己。
- 29.世界上有两张积分牌，第一张叫外部积分牌，它的分数由别人来填写，你的分数是你的职业、你的存款数字、你开的车、你住的房子、社交媒体上的点赞数，以及你在别人眼中的样子。你活着是为了赢得掌声和羡慕，你所有的努力都是为了让这张公开展示的积分牌看起来更漂亮。第二张叫内部积分牌，它的分数只能由你自己填写，你的分数是你的好奇心、你的求知欲、你内心的平静、你拥有的深度关系、你帮助过的人、以及你是否忠于自己的原则，你活着是为了取悦你自己，为了成为一个你自己尊敬的人。
- 30.如果你太容易就取得成功了，那么你还会进步吗？（就像今天，就是因为你受挫了，你又学到一点东西，又进步了一点。）
- 31.你看看，找到一部好看的，你那里舍得抽身出来啊。（同样，假如说，你现在掌握了大量资源，你也会沉溺于物质享受的，你怎么舍得抽身出来呢。）（你累了，工作上的东西让你烦了）（你从来都是，看中享受的，你不会让自己累的，苦的。）（如果你一直以来，都是习惯拼搏，习惯付出，习惯不怕苦，那又不一样）（所以，工作上的东西，让你觉得累，觉得烦，还真是非常好的锻炼。就是要让你累一累，让你烦一烦，让你苦一苦。）
- 32.如果你怕苦，怕累，怕烦，那么，其实你还是不要成功，不要掌握大量资源的好。
- 33.怕苦，怕累，怕烦，是谁怕呢？是谁决定了的？是你掌控做事的那部分想法吗？是某种看法？是某种认知？还是什么呢？那它为什么怕呢？不怕不行吗？为了达到目标，苦几下，累几下，烦几下，不可以吗？
- 34.你认为的全力以赴，是什么样的。难道说，你做了一次努力，结果不行，那么就已经努力过了，没任何办法了？这就是你理解的用尽全力？（别人理解的用尽全力是咋样的。拼命努力一次是很平常的事，拼命努力一次又一次，直到成功。这，才是用尽全力啊。）
- 35.倘若你真的掌握了大量资源，你会不会连那些书都不看了？你还剩那么多书没看呢。
- 36.你看看，要是你掌握了大量资源的话。（今晚，十点钟，九不搭八的东西，打电话来问你）
- 37.我们是要，求稳。但是，其他国家呢。有些国家已经被这些，整得水深火热，简直活不下去了，那自然他们会拼了命，想法子搞事啦。
- 38.你平时很是很多机会坐下来。那么，利用起来，写东西啊。写东西，可以帮助到你保持思考，保持思维不僵硬。（你平时，不是觉得，老是坐着，然后人的思维都反应迟钝了。）
- 39.在低谷时候，你提升起来的速度，肯定比平时快啊。（反正我已经在谷底了，没什么负担。而且，提升空间巨大）
- 40.遇到问题，你会不会去寻找力量来解决。（例如，主动去两馆，主动写下来，主动去搜）。一般不会，你只会自己尝试去解决，一旦自己试过，觉得解决不了，便觉得，这是个无法解决的问题。你没有想过，要寻找力量来解决吗？那里有那么多无法解决的问题呢，都是可以解决的。你一定要有这个意识，去寻找力量，来解决。你要去调查研究啊，你要想方设法啊，你要去寻找力量啊，你要做点东西啊。有这种意识和没有这种意识，差距就非常大了。
