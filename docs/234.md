# 一种值得警惕的状态。（2026年8月4日） 

- 1.其实还是有种担心，倘若自己真的掌握大量资源。那自己会不会通不过这另一种考验啊。那不如这样吧，你写一些小说，就写主人公掌握大量资源后，因为种种原因，没通过考验，然后让人扼腕叹息的失败了。经常写这样的小说，会不会对你自己有帮助呢？
- 2.掌握大量资源其实不算什么。要是你能通过，这另一种考验，那你才算了不起。
- 3.我们太擅长把一件不该做的事，做得越来越高效。
- 4.写作不是书法，不是重复越多越好。针对特定目标（如，其标题，写金句，搭结构）的刻意练习，才是有效的经验。
- 5.
    - 1.标题：它是通知还是诱惑？
        - 差评习作特征。《关于XXX的思考》《我的读书笔记》《一周小结》（这是写给你自己看的。）
        - 好评习作特征。《我多了20本写作书，总结了这3条避开指南》《为什么你坚持写作半年，还没赚到一分钱？》
        - 分析：你的标题是否包含了痛点，数字，悬念？
    - 2.开头：前3秒有没有钩子？
        - 差评写作特征。冗长的铺垫，或者像教科书一样定义概念。“写作是一件很重要的事。。。。”
        - 好评习作特征。直接讲一个扎心的小故事，或者抛出一个反直觉的观点。“昨天，我又删掉了一篇写了3000字的稿子。”
    - 3.结构：是水流还是台阶？
        - 差评习作特征。一段到底，或者段落之间没有逻辑，东一榔头西一棒子。读者读着读着就忘了前面说了啥。
        - 好评习作特征。小标题清晰，每段有一个中心局，逻辑是呈递进关系（是什么-为什么-怎么办）。
        - 分析：把你的文章打印出来，只看加粗的字和小标题，如果能串成一篇完整的短文，说明结构过关。
    - 4.语言：是堆砌还是说话？
        - 差评习作特征。喜欢用大词、形容词、成语，或者文皱皱人书面语“此时此刻，我的内心是波澜壮阔的。。。”
        - 好评习作特征。口语化，多用动词，短句为主。“我的心很乱。”“这事搞砸了。”
        - 分析：试着把你的文章大声朗读出来，如果觉得拗口，或者平时说话绝不会这么说，那就是“学生腔”或“自嗨腔”。
    - 5.结尾：是“句号”还是“路标”
        - 差评习作特征。“这就是我的看法，谢谢大家。”或者强行升华喊口号。
        - 好评习作特征。总结核心观点+引导互动。（“你在写作中遇到过这个问题吗？”）+引导关注（预告下期内容。）
        - 分析：你的结尾有没有促使读者产生下一次见面的期待？
