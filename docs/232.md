# 两个标尺：有趣，有用。（2026年7月26日）

- 2.要知道，失败的可能性也是存在的。如果你不努力，不能坚持下去的话。
- 3.跟战争任何一个方面一样，通信和电子对抗是一个道理。有主观能动性的，想打赢敢打赢的，不怕牺牲也要争取胜利的，跟没有主观能动性的，当一天和尚撞一天钟的，开两枪算是对得起委员长的，肯定不是一回事。
- 4.真的做成了，那肯定不一样啊。别忘了，你是多么不能容忍别人看不起你。
- 5.累了，从来不会主动去休息。只会要么拼命吃东西，要么找刺激的东西来看。
- 6.写作，是能发挥你最大长处的事了。（假如这是真的，那么，这件事你做不做？有困难，有障碍，你做不做？）
- 7.都可以的啊。纸质投稿；番茄；起点；公众号。只不过，现在，公众号这种形式，看起来是最适合你的。是能提升你的写作能力的。（能快速让你开始；没有过多的限制；能提供反馈；能除了发布作品，还能打造人设；）那假如说，你在公众号一直没有取得较大突破，你随时可以考虑其他的途径的啊。
- 8.所以，当你真的成了，取得一些资源了。相对来说，你会比以前更有话语权了。如果看到身边有人喜欢看书，家人不支持他（她），整天只会买书，看书有什么用？你可以，选择支持一下，你可以举一下自己的例子来说。
- 9.值班可以写东西，写大纲，写详纲，写人物概述，列出十个创意，看老师的课程。（想得倒是挺好，最后，做成的不多。）
- 10.从有趣的问题开始。如果你翻到空白页还是觉得无话可说，想一想，你语言上的贫乏可能就是因为你缺少问题意识。如果你写的东西看起来很无趣，甚至你自己都不愿意看，那么看看你能不能写出一些问题（而不是答案），从问题开始，一切都会变得更加有趣。
- 11.读者选择看一样东西的因素里面，我们提取其中最重要的关键词：有趣，有用。
- 12.好了，你就用这两个简单的标尺，去衡量你自己的内容就可以了。最好是既有趣又有用，退而求次，也要做到要么有趣，要么有用，既无趣又无用的，不仅不合格，还是不能发表的，别说发表，连做都不应该做。
- 13.所以，你的审稿流程应该是，这个内容对读者来说是有用的吗？若是有，有多大用处？既然这个内容的确是有用的，那么我如何才能让它看起来更有趣一点？哪怕更有趣那么一丁点，都是非常有价值的。
- 14.还是需要有一个机制才行。你不是觉得自己已经找到路子了吗？那你开始做啊，做了以后结果如何，有什么反馈，似乎不咋滴啊。那，问题出在那里？你分析一下啊。还不够好？只是单纯的需要多点时间？那还需要多少时间呢？你确定只要再给点时间就行了吗？
- 15.总之，这需要一个机制。首先，你既然认为自己找到路子了，那你就应该赶紧去做。做了之后，现实世界给你的反馈是什么，和你之前的设想一样吗？如果不一样，问题出在那里？要如果改进？如果一样，有那些东西是做多了的？就是说，需要一个定期检讨的机制。
- 16.黄易的小说，里面是否有些套路，可以学得到。
- 17.文学来源于生活，就在普普通通的生活中，这是千真万确的。关键是你对生活的感受
。
- 18.我绝对不是给大家泼冷水。真正有志于文学的青年，首先要考查一下自己的感受能力。有个名人说过，世界上只有一件事比犯错误更坏，那就是迟钝。你考查一下你对生活的敏锐。生活还都是很平凡的，只要你找到了自己的敏感区以后，你不要惧怕别人也写了，因为你总会找到你自己的角度。
- 19.当我们有意识地寻找自己地敏感区以后，接下来便是有意识的发现。契诃夫说过，新手永远靠独特的东西赢得社会的承认。我想，这个独特，就是新的发现。所以，足见发现对于文学创作的至关重要。
- 20.所以，有两点是值得大家注意的。一是，要保持对生活的新鲜感。大家每天的生活差不多是一样的，你只有保持对生活的新鲜感，才能在没意思中发现意思，才可能把没意思的东西写出意思来；二是，应该刻意培养自己对生活的感受力。后天怎么培养呢，我认为，还是要培养你自己对人生敏锐的目光，把这个变成一种习惯。
- 21.其实，纸媒相比新媒体文对新手小白更加友好，尤其是投稿报纸，字数不多，1000-1300就够。如果投杂志，2000-2500字左右。选题也多，生活处处可见。
- 22.新手小白可以写什么呢？我结合自己写过的文章整理了一些选题。
    - 1.亲情类。除了写自己与亲人之间的真情，也可以写和他们相关的物件，如《奶奶的蒲扇》《爷爷的烟袋》《老父亲的自行车》等。
    - 2.乡土乡情类。家乡的花草树木，小河流水，老屋等一切事物。
    - 3.美食类。家乡的美食、旅游地的美食、应季、应节事物，和某个人有关的普通美食。如《外婆的一碗绿豆汤》《奶奶做的面疙瘩》等。
    - 4.读书类。书评，读书的故事，与读书相关的都可以，如晨读的美，我与某本书等。
    - 5.节气类。二十四节气，四季中有代表性的气象，如春天的雨，秋天的风，冬天的雪，如我写的《觅秋》，春天时可以写踏春。
- 23.找个自己喜欢的或者比较有感触的选题开始写，如果不知道怎么下笔，可以去“梅子搜报网”输入标题搜索范文，从仿写开始。也可以上“好稿网”看报纸范文，杂志可以下载“博看书苑”，从阅读开始培养语感，看相关选题别人怎么写比如开头结尾，结构，过渡，如何点题，升华等，这些都可以拆解。
- 24.总之，一定要写起来，一千来字的文章投报纸，新手小白也有机会，投稿时末尾记得附上作者简介。
- 25.写网络小说，就是搭建幻想屋。
- 26.三九音域说，我们每个人的心里，都藏着一个想要住进去的世界。但这个世界需要借助工具才能抵达。有些人，凭借阅读抵达；有些人，凭借想象抵达。而写作，就是帮助读者造梦的过程，并帮助读者住进这个“幻想屋”。
- 27.打开你的备忘录吧，再定一个30分钟的闹钟。
- 28.
    - 1.第一步，像跟朋友吐槽。想象对面坐着好朋友，心里话倒出来。可以这样开头，我跟你说啊，昨天那件事，真实太气人了。不停笔，不删除，想到什么写什么。有错别字，句子不通顺都没关系，先倒出来再说。
    - 2.第二步，自己问自己。读一遍，找出最想说的那个点。然后自问自答，这个观点对吗？为什么？能举个例子吗？例如，下班后写作靠什么？靠把写作变成习惯，到点就写。白天站10个小时，晚上8点30做到餐桌前，拿起手机就开始。不想写？那就写写，今天不想写，写着写着，就想写了。一问一答，观点就透了。
    - 3.第三步，整理。删掉啰嗦的，加小标题，写个勾人的开头，写个有力的结尾。你看，问题一具体，文章就出来了。
- 29.这也是为什么我一直建议大家记录读者问题，学员问题，客户问题和自己踩过的坑。因为这些东西才是真正的内容入口。你每天凭空想，写什么，很容易写散的。但你围绕一个真实问题写，文章就天然有方向。读者也更容易觉得，这篇文字就是写给我的。
