# Ryan的卡片系统。（2026年9月14日） 

- 1.Ryan Holiday（瑞恩。霍利迪）读书时会在页边做标记，把重要句子折起来。读完以后，他通常不会马上把这些内容扔进某个数字笔记软件，而是过一段时间重新翻书，把真正值得留下的内容抄到一张张4x6英寸的实体卡上。卡片顶部写一个主题，比如勇气，自律，死亡，权力，故事。然后把它放进对应的盒子。
- 2.一本书读得越多，材料越容易失控。你保存了50个网页，200条高亮，几十万字笔记，真正开始写时，反而不知道应该从哪里开始写起。
- 3.所以Ryan逐渐形成了自己的卡片系统。他不会因为一句话“以后可能有用”就把它留下。他需要判断这条材料究竟属于哪个主题，为什么值得保存，将来可能和什么东西发生连接。
- 4.这个过程其实已经是在写作。
- 5.很多人把阅读和写作分成两件事，前一半输入，后一半输出。
- 6.Ryan的方式更接近持续加工，每读到一个故事，都问一次，“它意味着什么？”，每做一张卡片，又问一次，“它应该放在哪里？”。等到真正开始写书，作者已经思考过这些材料很多次。
- 7.Ryan得到一条对他影响很深的建议，正式写一本书以前，先试着用一句话，一段话和一页纸分别解释这本书。如果一句话说不清，说明自己还没有真正理解它。
- 8.这听起来很简单，实际非常难。因为写5000字有时候比写一句话容易。5000字可以解释，补充，绕路，而一句话必须决定什么才是核心。
- 9.Ryan后来反复提醒写作者，真正困难的部分，经常发生在大量写作以前。作者要先“破解”一本书，知道它到底想说什么，再开始处理具体章节。
- 10.这也是一个很好的自检方法。如果一篇文章已经写了2000字，却还无法用一句话说清楚它究竟想让读者记住什么，大概率还需要继续想。
- 11.这是一种很值得学习的写作习惯，看到一个好观点，先别急着记观点，看看有没有一个能把它变得具体的故事。例如，“人在压力下要保持冷静”，读完后很快会忘，但是，你如果能变成一个故事，说一个人在所有人慌乱时做了什么，那么会记得更久。
- 12.还是尽快把这个总纲和贴图搞一下。也可以方便自己，不然，自己都搞不清，那个武器写了，那个没写。
- 13.钱德勒的做法是，找一篇待拆的小说，写出详细大纲，然后对着大纲重写，再比较自己写的跟原著的差别，返回来再重写，然后再比较，再重写。。。。最后就能写得挺像样了。
- 14.今天一件小事让自己感动。你赶公交车，差点赶不上了，一个陌生大妈，看你跑来，主动招收，示意司机等你一下，就是因为这样，你最终赶上了。（一个陌生人的善意，即使是一个不起眼的帮忙，也给你一种很温暖的感觉。）（所以啊，当有一天你掌握了一些资源，你有能力帮一下，确实需要帮助的人，那么，你还是要帮助别人。）
- 15.不是说我 彻底不写稿了，而是把脏活累活交给AI了。我现在的工作流是这样的，每天花20分钟看行业动态，列几个关键词给AI生成3-5个选题方向，自己挑一个有感觉的，给AI写初稿（一般会换几个模型，DeepSeek逻辑强，豆包写生活类比较顺），我自己加案例，改开头，调语气--这一步AI替代不了，因为只有我知道读者想看什么，会存起来。定时发布从每天写3小时，变成现在40分钟搞定。
- 16.你看，他们写标题，也不是每篇阅读都很高的，也是靠广撒网，量大取胜的。偶尔有一篇10+的，剩下的都是几十的，差距就这么大。就是采用广撒网战略，有一个进入流量池，就越滚越大。（那么，你也应该这样。这个系列写完后，你也每个单篇写个吸引眼球的标题，广撒网，多次尝试，不断的试，总会有一篇进入流量池的）（不管怎样，我试101遍，总会有一篇火爆吧。）
- 17.格力技校首届招生。学费最高1.5万/学年，董明珠出任校长，宣称“入校即入企，毕业即适岗。”，招生简章显示，首届招300名学生，学费9000～15000元/学年，招生对象为全国应往届初中毕业生，年龄15～18周岁。针对优秀学员，另设国家奖学金，助学金，免学费等政策。
- 18.你是不是也曾羡慕别人的文章动辄几万的阅读量。但是，有写过爆款的人都知道，动辄10万+的爆文流量也行短时间内可以帮你积累大量粉丝，但是要真正变现的时候，1000个精准粉丝的价值，要远大于10万泛粉丝。
- 19.凯文。凯利在《1000个铁杆粉丝》里说的很清楚，你不需要几百万普通粉丝，只需要1000个铁杆粉丝，就可以养活自己了。
- 20.泛粉丝被你的标题吸引过来，看完就离开；而真正的精准粉丝则是被你个人的价值观和能力吸引而来的，他们才会为你的价值买单。
- 21.所以，即使你的阅读量只有几十，也不要担心。你要做的就是持续输出自己的经验和价值观，让认可你的人留下来。
- 22.而长久写作的目的，不在于篇篇都是爆款，而在于能持久的被看见。只要你在一个垂直细分领域能够持续的被看见，你就可以慢慢的积累起来这个领域的影响力。
- 23.苏州50岁女子不慎落水，因不会游泳强压恐惧仰漂近1小时；路过市民，以为是假人模特，后来看见戴着手镯立即报警。
- 24.初步设想，路径是这样。先整完108系列，然后贴图108系列，然后总纲，然后尝试365次（起吸引眼球的标题），直到有一款爆款，然后四年小目标。
- 25.你能动用的资源比别人多，那么，你就比别人高人一等吗？
- 26.假如你真的掌握大量资源，你怎么对待身边的人。你是坚决不让她们知道吗？
- 27.Nathan问了他一个问题，AI已经可以在几秒钟内生成一篇结构完整、语言流畅的文章，一个写作者以后靠什么脱颖而出。David的回答很直接。他说，一个人写不出好东西，通常有三个原因，没有好想法；有好想法，却不敢真正说出来；最后才是不会写。
- 28.过去，第三个问题会挡住很多人。脑子里明明有想法，却不知道怎么组织，标题不会写，句子写不好，结构很混乱。今天，Claude，ChatGPT ,kimi等已经能够承担其中大量工作。
- 29.当表达越来越廉价以后，一个写作者真正稀缺的能力，会逐渐向更上游移动，你有没有看见什么，有没有形成自己的理解，又有没有一个真正属于自己的判断。
- 30.David当然也使用AI。他会语音输入，让工具帮助整理结构，也会用它修改和压缩文字。
- 31.可AI进入的是写作链条的后半段。更重要的事情发生得更早。先去生活，去看一些别人没有看的东西。进入几个距离自己很远的世界。然后慢慢形成自己的判断。等到真正有东西想说的时候，再让AI帮助我们把它说得更清楚。
- 32.AI可以让越来越多的人拥有一篇像文章的文章。真正会越来越稀缺的，是读完以后，别人能够感觉到，这背后确实站着一个有自己判断的人。
- 33.要让你的大脑知道，真正重要的是什么，而不是它以为的东西。
- 34.像昨晚发生的事，你也可以提炼出来一个点。（尝试用一句话来概括。深夜命令下属打电话找人，也就是一个不知道轻重缓急的领导。）那么，你可以分析一下，这个领导是怎么想的，她的成长经历了些什么，才会这样。如果你要创作这样一个人物，你该怎么写？
- 35.多花时间，去考虑事情的另一面，以及是否有其他的可能性。
- 36.就像上学听课时一样，如果老师一味讲课本理论，没多少人愿意听。但只要他穿插一些真实的故事，真实的经历，具体的例子，那么大家就听得津津有味。
- 37.那么，写公众号文章也一样的吧。多讲自己的真实经历，真实踩坑，真实感悟，用具体案例佐证观点。也就是文字尽量接地气，读者才愿意从头读到尾，完读率才会高。
- 38.有些方面，可以追求极致。例如，你工作电脑的纯洁程度，例如，你在写作时，用词的准确度。
- 39.思考一下，你看什么报纸和杂志，能给你带来更多的灵感，让你有更多东西可以写呢？
