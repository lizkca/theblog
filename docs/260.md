# 挑一样东西学透，富兰克林法。（2026年11月5日） 

- 1.斯坦福大学有一门设计行为学课程，是全世界公认的，“普通人尽快提升自己”的有效方法论。它是BJ。福格教授用十几年的时间和几万学生参与者一起研究出来，并验证过的方法。
- 2.所以这个方法还有另外一个名字--福格行为模型。
- 3.问题不在于你不够努力，也不在于你不够聪明，而在于你从来没有设计过，一个真正能提升自己的结构。
- 4.大多数人喜欢讲目标、讲梦想、讲自律、讲意志力。但真实的逻辑是，当自我提升的能力需求太高，提示不明确，动机起伏不定的时候，再强的愿望都没用。
- 5.所以，正确的问题不是，怎样提升自己？而是，怎样让自己愿意去开始？
- 6.工作上的东西为什么觉得难受？其实也会你的看法有关。你觉得，做到这样的程度，做这样复杂的东西，是难的。（是不是难，只是你自己觉得而已。也就是你和自己平日做到的程度，做的东西比而已。）
- 7.网文创作工坊，成功入驻workbuddy技能市场了。
- 8.我前阵子翻github的时候发现，微软早就把一整套课程免费放出来了，只是没怎么吆喝。8门课，全部开源，全部带简体中文。
- 9.人的力量。有没有什么人，能对你目标的东西，提供助力呢？没有吗？一个都没有？去哪里能找到一个呢？
- 10.写作很重要的一点，把你写的东西当真。这样，才能写下去。你认为你写的东西都是真的，这样，你才能从你写出来的东西的基础上，继续写下去。（你写人物受了伤，要真的感觉到痛；你写主角感受到温暖，要真的从内心觉得温暖；）
- 11.规划提出，到2030年，我国新型电池产业规模实现稳步增长。全链条创新能力持续增强。全固态电池初步实现规模化应用，长寿命锂电池循环寿命达到15000次，头部企业产品缺陷率达到PPB级，新型电池技术与清洁能源，用能终端加快融合创新发展，国际贸易投资一体化深入推进。
- 12.滚雪球战术。如何用在写作上，让写作能力也像滚雪球一样，越滚越大。
- 13.如何完成自己真正意义上的第一部作品，收获读者，收获信心，收获金钱。
- 14.有没有一些AI，是帮助你学会写作的，而不是代替你写作的。
- 15.会不会像学英语一样呢。总的来说，你也花费了不少时间在英语上了，但是，几年下来，还是没什么成果一样。写作，你也只是在业余搞一搞，又怎么避免这种情况呢？还是要，抓住一点，要学透，反复练习，练到通透为止。（富兰克林的学习写作法，练到通透为止。）（范文不限，科幻，玄幻，武侠，公众号的爆文，等等都可以。）（开发一个软件帮助自己，练习富兰克林写作法。并且，也可以内置日历打卡，番茄钟。）
- 16.可以以张学良的传奇故事为原型，写一部武侠小说。
- 17.今天早上，这个算一次成功的体验吗？你能脑子浮现画面，然后根据画面写东西。这，应该是非常好的体验，做点什么努力，让自己再多次重新有这样的体验，并且形成稳定的能力。
- 18.你看，只要你真的去做。哪里存在什么，没办法，你做着做着，办法就来了。
- 19.知足不辱，知止不殆。
- 20.小小挫折，又算得了什么。下一次做好点，就是了。
