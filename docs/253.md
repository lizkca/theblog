# 普通用户刷公众号时，很多时候不是为了学习，而是在找消遣；三个要经常提醒的东西。（2026年9月19日） 

- 1.我现在，即使没有掌握大量资源，我也经常体验到了，满足，充实的感觉了。（通过，去体育馆，图书馆，等等的活动。），那么到你真的掌握大量资源，其实，你也是要通过这些活动，来获得满足，充实的感觉。而不是说，你就用资源来换取满足感充实感。那样的话，很有可能，反而会让你失去满足感充实感。
- 2.两个经常要提醒的东西。
    - 1.没事少用点电脑，非必要少用；
    - 2.在单位，记得进入认真，工作，警醒的状态。
- 3.公众号里，居然有一个叫，加热的工具。可以让你花钱，增加点流量。要试一下吗？
- 4.认真，警醒，工作状态，（不要昏昏沉沉，不重视，不警觉）
- 5.作者最大的敌人，是忘记读者并不知道，作者已经知道的事。
- 6.公众号的受众是极其广泛。存在这样的情况，一些你认为不咋样的东西，说不定，会有一群群体非常欢迎。
- 7.也可以说，公众号存在很多的不确定性因素。你坚持做下去，肯定有意想不到的收获。
- 8.盖茨说，这主要有两个原因。
    - 1.我们已经跨过了一系列临界点。无论是生物能力、网络攻击能力、心理和社会影响，还是对就业市场的破坏能力，甚至是AI的失控风险，我们都已经开始看到问题的迹象。
- 9.巴菲特说，我买不到时间，也买不到爱。我为什么每天满怀期待地跳下床？因为我热爱所做的工作，也爱我的朋友们。财富上的成功不是我的快乐之源，它只是一个副产品，工作本身，以及和我一起工作的人，那才是真正的回报。
- 10.你应该喜欢你正在做的事，你写出来的东西，以及那群喜欢你写的东西的人。
- 11.也就是说，你的目标应该是写出好的东西，并且获得很多人喜欢你的作品，然后给他们带来价值。（你想一下，有人喜欢你写的东西，你能给别人带来了价值，那其实就够了。）
- 12.当你满了一千粉丝，但你不知道每天写什么。那么，其实你可以把每天自己想的东西写下来，也就是相当于给你的粉丝们，汇报一下，你今天想了什么。
- 13.平台推荐系统，不是先判断内容咋样，而是先看数据反馈。
- 14.点击、停留、评论、转发、互动，只要这些数据持续不错，系统就容易默认，这条内容对部分用户有吸引力，值得继续分发。
- 15.所以你会看到，有些内容明明很浅，但阅读量就是高。
- 16.因为普通用户刷内容时，很多时候不是为了学习，而是在找消遣、认同和参与感。
- 17.每天，除了知乎，还有什么地方，可以看到大量的八卦呢？豆瓣，微博啊。
- 18.在知乎，新闻，微信公众号，看到一个标题，就从这个标题出发，提炼出一个题目，以此为题，来写一篇文章。（可以写成小说来演绎一下，可以写议论文，写散文，写诗歌等等。任何题材都可以）
- 19.当你写不下去，去读一读别人写的。说不定，下一部名著，就藏在你偶然读到的一个句子里。（你读到某句话，受到启发，因此写出一本好书出来。）
- 20.人天然就对能说出自己名字的人，有好感。
- 21.你看啊，一件很小的事，也把你影响到不得了。（你是从，会不会受到指责，这个角度来判断的。一件事可能很大，但是不会受到指责；另一件事，可能很小，但是有可能受到指责。）
- 22.所以啊，不要那么高的期望。你把这十年过好（2026-2036），就哦弥陀佛啦。
- 23.三件经常要提醒自己的东西。一是在家少用电脑；二是在办公室要进入工作、警醒、认真状态；三是能平安过好这十年就哦弥陀佛了。
- 24.自己还是有非常薄弱的环节的，不要忘了这一点。
- 25.看来，平日里，还是有强迫自己嘛（也就是这次发癫，才发现了这样东西。）
- 26.把任务切割成，可中断，可恢复，的小小块，非常重要。
- 27.你看，小孩放学回来。你不做其他东西，专心和她聊聊天，非常有意义啊。（刚上毕业班，经过一个假期，压力还是有点大。需要一些适应）
- 28.一天工作12小时，手指被针扎穿，还要继续干，不实习不发毕业证。。。央视曝光职校实习灰色产业链，学校、中介、工厂分利，学生成为明码标价的商品。
- 29.真的要作出点东西出来，才能赢得别人的尊重。
- 30.大众对于精神事物产生兴趣，这是20世纪90年代生活的一个特征。对有关天使、奇迹、幻觉和来世的书籍感兴趣的读者大为增加，为出版商打开了销量，也开辟了比较严肃的书籍市场。
